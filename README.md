# Rubber PoC
This is a proof of concept for a chatbot that can generate audio from text using a large language model and a text-to-speech API.

## Prerequisites
- Node.js
- Yarn
- Docker
- Docker Compose
- Local LLM API (ex: LM Studio with ``google/gemma-3n-e4b`` model installed)
- XTTS API

## Installation
To get started with the Rubber PoC, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone git@github.com:HardModeLab/rubber-poc.git
    cd rubber-poc
    ```

2.  **Install dependencies:**
    ```bash
    yarn install
    ```

## Run the application
```bash
yarn start
```
